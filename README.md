# Weekend project: Cologne heat planning (Wärmeplanung) 🌍🌡️💧

## Geothermal screening with Google Earth Engine

This project provides a **Google Earth Engine (GEE)** screening for shallow **geothermal potential in Cologne**. The map shows relative suitability, intended to identify where more detailed site-specific studies are worth pursuing.

### 🗺️ Suitability Legend

- 🟢 **Green:** Favorable conditions
- 🟠 **Orange:** Possible, but with higher effort
- 🔴 **Red:** Higher constraints (not automatically excluded)

### 🗂️ Data Sources and Proxy Logic

Powered by **Google Earth Engine**, the analysis uses:

- **ERA5 Land:** Soil temperature and soil moisture
- **DEM:** Slope analysis
- **ESA WorldCover:** Used as a sealing proxy

### 🚀 Takeaway

Cologne requires a balanced technology mix. District heating, heat pumps, and shallow geothermal systems should complement each other. This screening helps streamline the planning process by identifying high-potential areas for deeper investigation.

### 🛠️ Future Improvements

For more precise and robust results, additional data layers are required:

- 💧 Water protection zones
- 🌊 Flood risk areas
- 📊 District level summaries
- 🏗️ Clear distinction between vertical boreholes and horizontal collectors
